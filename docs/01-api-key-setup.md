# APIキー設定手順書

このシステムの秘密情報は、すべて **GAS の Script Properties（スクリプト プロパティ）** に保存します。
コード・スプレッドシート・チャット・メールには絶対に貼り付けないでください。

## 登録する項目一覧

| キー | 必須 | 内容 | 例 |
|---|---|---|---|
| `CLAUDE_API_KEY` | ✅ | Claude API キー | `sk-ant-...`（実際の値は書かない） |
| `WP_BASE_URL` | WordPress利用時 | WordPress サイトのURL（https 必須、末尾 `/` 不要） | `https://example.com` |
| `WP_USERNAME` | WordPress利用時 | WordPress のユーザー名（投稿者以上の権限） | `editor` |
| `WP_APP_PASSWORD` | WordPress利用時 | WordPress のアプリケーションパスワード | （空白入り24文字） |
| `CLAUDE_MODEL` | 任意 | 使用モデル。既定は低価格の `claude-haiku-5-5`。品質が足りない場合は `claude-sonnet-5-5` | `claude-sonnet-5-5` |
| `CLAUDE_EFFORT` | 任意 | 思考の深さ `low` / `medium` / `high`。既定 `medium` | `low` |
| `CLAUDE_MAX_TOKENS` | 任意 | 出力トークン上限。既定 `16000` | `16000` |
| `CLAUDE_USE_FALLBACK` | 任意 | Claudeが応答を控えた場合に別モデルで続行する機能。既定 `true`（対応モデル＝Sonnet 5.5 / Opus 5.5 でのみ有効。Haiku 5.5 は非対応のため自動的に送信しない） | `false` |
| `MAX_GENERATION_ATTEMPTS` | 任意 | 仕様外のとき書き直す最大回数（1〜3）。既定 `2` | `1` |
| `PROMPT_VERSION` | 任意 | プロンプトの版。既定 `v2`（改善版）。`v1` で改善前の初期版に戻し、記事を比較できる | `v1` |
| `SERVICE_NAME` | 任意 | まとめで控えめに紹介するサービス名。既定 `キンタイ Cloud` | `キンタイ Cloud` |
| `SERVICE_CATEGORY` | 任意 | サービスの種類（記事との関連を判断する材料）。既定 `勤怠管理サービス` | `勤怠管理サービス` |
| `SERVICE_FACTS` | 任意 | 記事に書いてよいサービスの確定情報（公式に確認済みの機能など）。**未設定なら機能・料金・実績は一切書かれない** | （公式資料で確認した内容のみ） |

WordPress の3項目が1つでも未設定なら、WordPress 連携は自動的にオフになり、スプレッドシート保存だけで動作します。

## 1. Claude API キーの取得

> ⚠️ API の利用には料金が発生します。取得前に料金ページを確認し、**利用上限（Spend limit）を必ず設定**してください。

1. Claude Console（`https://platform.claude.com/`）にログイン
2. 「Settings > Billing」で支払い方法を登録し、**月の利用上限**を設定（例：最初は少額）
3. 「API Keys」→「Create Key」
4. 名前（例：`gas-blog-generator`）を付けて作成
5. 表示されたキーをコピー（**この画面を閉じると二度と表示されません**）

### モデルの選び方と料金の目安

| モデル | 単価（入力 / 出力、100万トークンあたり） | 1記事の概算（入力3千＋出力6千トークン、書き直しなし） | 用途 |
|---|---|---|---|
| `claude-haiku-5-5`（既定） | $0.10 / $0.50 | 約 $0.003 | まずはこれで運用 |
| `claude-sonnet-5-5` | $2 / $10 | 約 $0.066 | 文章の質が足りないとき |
| `claude-opus-5-5` | $4 / $20 | 約 $0.13 | 特に高い品質が必要なとき |

- 単価は 2026-11-03 時点の公表値です。**実際の単価は Console の料金ページで確認**し、改定されていたら `src/Config.js` の `MODEL_PROFILES` を更新してください
- 出力トークンには AI の思考（thinking）分も含まれ、課金対象です。書き直しが発生すると最大約2倍になります
- 実際の使用量は「記事本文」シートの「入力トークン」「出力トークン」「API呼び出し回数」「推定費用（USD）」列と「実行ログ」で確認できます
- 費用を抑えたい場合は `CLAUDE_EFFORT=low`、品質を上げたい場合は `CLAUDE_EFFORT=high` または `CLAUDE_MODEL=claude-sonnet-5-5`

### Haiku から Sonnet に切り替える手順
1. Script Properties の `CLAUDE_MODEL` に `claude-sonnet-5-5` を登録（Haiku に戻すときはプロパティを削除）
2. 「設定状況を確認」でモデル名と「フォールバック：有効」を確認
3. 品質を比べたい記事を「選択行を再生成（上書き）」

## 2. WordPress アプリケーションパスワードの発行（任意）

前提：WordPress 5.6 以降、サイトが **https** で公開されていること。

1. WordPress 管理画面にログイン
2. 「ユーザー > プロフィール」を開く
3. 下部の「アプリケーションパスワード」で名前（例：`gas-blog-generator`）を入力 →「新しいアプリケーションパスワードを追加」
4. 表示されたパスワード（`abcd efgh ...` の形式）をコピー（再表示されません）

> ログイン用のパスワードではなく、**アプリケーションパスワード**を使ってください。
> 不要になったら同じ画面から「取り消し」でき、ログインパスワードには影響しません。

**権限について**：下書きの作成には「投稿者」以上の権限が必要です。運用では専用ユーザーを作り、「投稿者」権限にすると、万一漏えいしても公開済み記事の編集はできません（投稿者は自分の投稿のみ編集可能）。

**アプリケーションパスワード欄が表示されない場合**：セキュリティ系プラグインやサーバー設定で無効化されていることがあります（[トラブルシューティング](03-troubleshooting.md)参照）。

## 3. Script Properties への登録

1. スプレッドシートの「拡張機能 > Apps Script」を開く
2. 左メニューの ⚙️「プロジェクトの設定」をクリック
3. 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
4. 「プロパティ」にキー名（例：`CLAUDE_API_KEY`）、「値」にコピーした値を貼り付け
5. 必要な項目をすべて追加して「スクリプト プロパティを保存」

## 4. 登録の確認

スプレッドシートを再読み込みし、メニュー「記事生成 > 初期設定 > 設定状況を確認」を実行します。
値そのものは表示されず、「設定済み／未設定」だけが表示されます。

WordPress を設定した場合は「WordPress接続テスト」で、ユーザー名と投稿権限を確認できます（投稿は行いません）。

## 5. 安全に使うためのルール

- キーは Script Properties 以外（シート、コード、README、スクリーンショット）に書かない
- スプレッドシートを他人と共有すると、編集者は Apps Script からプロパティを見られます。**編集権限は信頼できる人だけ**に付与してください
- キーが漏れた可能性がある場合は、すぐに Console / WordPress で該当キーを無効化し、新しいキーを登録してください
- ポートフォリオとして公開する場合も、`.clasp.json` や実際のキーは公開しないでください（`.gitignore` で除外済み）
