# スクリーンショット（掲載する場合）

画像はマスキングした後のものだけをこのフォルダに置きます。マスキングする前の画像は `docs/images/raw/` に置いてください（Git の対象外です）。

## 掲載候補

| ファイル名（案） | 画面 | 見せたいこと |
|---|---|---|
| `01-menu.png` | スプレッドシートの「記事生成」メニュー | コードを操作しなくても使えること |
| `02-article-sheet.png` | 記事管理シート（ステータス・文字数・処理結果） | ステータス管理、「OK／注意／要確認」の表示 |
| `03-body-sheet.png` | 記事本文シート（トークン数・推定費用） | 使用量と費用の記録 |
| `04-settings-status.png` | 「設定状況を確認」のダイアログ | 秘密情報の値を表示しないこと |
| `05-wp-draft-list.png` | WordPress の投稿一覧（「下書き」表示） | 公開せずに下書きとして保存されること |
| `06-wp-draft-editor.png` | WordPress の編集画面（H2・箇条書き） | HTML の構造が正しく変換されること |
| `07-duplicate-block.png` | 再投稿時のエラーダイアログ | 二重投稿の防止 |

## マスキングする項目

| 項目 | どこに写りやすいか |
|---|---|
| メールアドレス・Google アカウントのアイコンと名前 | スプレッドシート・Apps Script の画面右上 |
| スプレッドシートID・スクリプトID | ブラウザのアドレスバー（`/d/` の後ろの文字列） |
| WordPress のサイト URL・ユーザー名 | アドレスバー、管理画面の右上、処理結果の URL 列、「WordPress接続テスト」のダイアログ |
| アプリケーションパスワード・APIキー | Script Properties の画面（この画面は撮影しない） |
| 実行ログの詳細 | 実行ログシート（ID・日時以外の内容） |
| ブラウザのタブ・ブックマークバー | 画面の上部（ほかのサービスや個人の情報） |

- できるだけアドレスバーを含めずに撮影します。
- ぼかしではなく、塗りつぶしで隠します（ぼかしは復元されることがあります）。
- 画像の位置情報などのメタデータは削除します。
- 記事の本文を写す場合は、法令を扱わない記事（例：Excel 勤怠管理の記事）を使い、全文は写さないようにします。
