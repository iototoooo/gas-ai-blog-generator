# samples

| ファイル | 内容 |
|---|---|
| `test-keywords.csv` | テスト用キーワード5本（`src/Setup.js` の `TEST_KEYWORDS` と同じ内容）。メニュー「初期設定 > テスト用キーワードを追加」で自動投入されます |
| `sample-article.md` | 教材サンプル記事の置き場所。現在は動作確認用のダミー記事が入っています |

## 教材サンプル記事の扱い

- 教材のサンプル記事は、スプレッドシートの「サンプル記事」シートに貼り付けて使います（`利用する` を `TRUE`）
- このリポジトリを公開する場合、**教材の著作物を含めないでください**。`sample-article.md` はダミーのままにするか、`.gitignore` に追加してください
- サンプル記事は文体の参考のみに使い、生成記事との25文字以上の一致は処理結果の「注意」として検出されます
